1.1.4. Pre-Class Activity #3: Building Vectors#

Files Needed#

Download the file(s) for this activity from MATLAB Drive. [Open MATLAB Drive folder]

Problem Generator#

This activity uses a problem generator, a special MATLAB function that gives you a unique problem based on your 8-digit Purdue ID (PUID). Most Pre-Class Activities in ENGR 132 will follow this same format.

To generate your personalized problem:

  • Download PCA03_skills.p from the MATLAB Drive link above.

  • Open MATLAB and make sure the file is saved in your current folder.

  • In the Command Window, type PCA03_skills(PUID), replacing PUID with the last 8 digits of your PUID.

  • Press “Enter” or click “Run”. Your personalized problem instructions will appear in the Command Window. Use that output to complete the problems below.

Activity Instructions & Submission#

MATLAB allows you to create and manipulate vectors using manual entry, transposing, and vector creation functions like linspace and colon notation. Vectors are a core data type in MATLAB and are used frequently in computations and data storage.

For each of the tasks listed in the problem generator output:

  • Follow the instructions for each task carefully, and use the specified MATLAB method to create your vectors. Do not use alternate approaches or hardcode numeric results unless instructed to.

  • Assign your answers to the following variable names: partA, partB, partC, and partD.

  • Confirm that your result matches the expected output in the Command Window.

  • Copy and paste the exact MATLAB command you used into the boxes on Gradescope.
